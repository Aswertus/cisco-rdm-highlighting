# Changelog

## [0.1.5]

No rule changes. Fixed the link to the original forum thread in the README (the short form returned
404).

## [0.1.4]

No rule changes. The release zip now includes `media/`, so the README inside it shows its screenshots.

## [0.1.3]

No rule changes. Issue forms for wrong or missing colours, setup problems and ideas, with a private
route for security reports; closed issues are locked after 30 days.

## [0.1.2]

No rule changes. Repository housekeeping: the pull-request check now also accepts issue forms
(`.github/ISSUE_TEMPLATE/*.yml`) and a workflow that locks long-closed issues.

## [0.1.1]

No rule changes.

- README: before/after and `show` output screenshots, and an illustrated setup guide.
- Setup starts with a terminal font override (Consolas 11, anti-aliased) — RDM's default font is
  thin enough to wash the colours out.
- Step 5 uses RDM's _Default profile_, so the profile applies to every SSH session.
- Settings path updated for RDM 2026.3: File → Settings → Entry Types → Sessions → Terminal.

## [0.1.0]

First release.

- `RDM-Cisco-Vivid.xml` in two sets: RDM's default black background and VS Code's `#232425`.
- `Daybreak-RDM-Dark.txt`: RDM terminal colours matching the VS Code background.
- 24 rules in the colours of the Cisco IOS LSP extension, case-sensitive, whole-word matching.
